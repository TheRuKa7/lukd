# ZERO-SUM: OMEN

Entry for the [Official Unity Game Jam 2026](https://itch.io/jam/official-unity-game-jam-2026). Theme: **Lucky Number**.

Fate rolls the digits. You rig the math. The game asks for *your* lucky number and builds the run around it.

- **Design doc:** [`docs/GDD.md`](docs/GDD.md). Refined concept, rules, story and cutscenes, art and tech plan, 7-day schedule.
- **Playable rules prototype:** [`prototype/index.html`](prototype/index.html). Open it in a browser. It is the reference implementation of the combat rules to port into Unity's `Core` assembly.

Hard deadline: **Sat 14 Nov 2026, 12:00 UTC.** A WebGL build is required.
