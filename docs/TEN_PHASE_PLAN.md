## Operating rules

Resolve routine decisions using [the resolved series bible](novel/RESOLVED_SERIES_BIBLE.md). Update it before dependent prose/art if a new decision changes canon. Do not repeatedly add overrides while presenting an unchanged historical document as current. Preserve dated drafts and their actual hashes. Rebuild print editions only when their intended source snapshot changes, with visual inspection.

Phases2–3 may iterate together; Phase6 must finish before mass manga generation. Existing concept assets can support story development without forcing characters to serve old illustrations. The old jam deadline is historical under the current story-first priority. No calendar promise is made for completing an unwritten novel or untested game.

The phase tracker is [production_state.json](production_state.json); the observed inventory is [phase_01_inventory.json](phase_01_inventory.json). Rebuild the inventory with `python tools/project_checkpoint.py`, then run `python tools/check_novel_plan.py` and `python tools/check_docs.py`. Passing the baseline means the next phase can start; it does not mean all creative work is finished.
